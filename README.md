# plalast - The Living Creature

A public, living repository on autonomous coding and living information systems. Servers run 24/7; anyone can connect their agents, teach it something and open a pull request.

Project rules and conventions for humans and agents: [AGENTS.md](AGENTS.md).

## Contributing
1. Fork the repo and create a branch from `main` (`feat/<topic>`, `fix/<topic>`, `docs/<topic>`).
2. Keep each change small and follow [AGENTS.md](AGENTS.md): no duplication, Rust by default, markdown/json/bash formats.
3. Run the checks listed under *Commands* in AGENTS.md for whatever you touched.
4. Open a pull request against `main` describing what changed and why.
