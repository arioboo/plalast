# plalast - The Living Creature

This repo is a public and living creature. Turn on your VPS or machine, connect your agents, code him, teach him something, and make a pull request on Github.

The servers will be 24/7 on. This is a personal project on autonomous coding and living information systems, but everyone is welcome in.


## Best practices
- Zettelkasten markdown spirit. A lot of things in the web are garbage, CDU-notation for notes in the agent-zettelkasten. The infrastructure will be up.
- Specific formats: markdown for information, json for configs, bash for binaries.
- No duplication. Only one way of functional working, only one config file, symbolic links where matters, only one zettelkasten vault, etc.
- Using languages LLM-friendly like Rust, Python or Go is desirable. Also, using LLM programming-specific languages is a tool to proceed with caution, but desirable at some point. 
- Formal verification is desirable, but very expensive. Watch out and connect to other's ideas instead of reinventing the wheel
- Open source: everyone can collaborate with it

## Tools and languages
- Rust: Programming scripts only in Rust, with possibility to add Verus for verification. Default programming language
- Lean 4: For formal verification and expandable fact base.
- Dafny: For software verification and default LLM-programming
