# Structure
note for agent: what follows is generated by the only memory brain, following rules and premises that are intended to be verified and formalized.

Paths are added here as they are created:

| Path | Content |
|---|---|
| `memory.json` | The memory, the brain: `config`, `primary` and `data`; with the params of `params.yaml`, every `.md` in the root and in `agents/` is generated from it (see `agents/BUILD.md`) |
| `params.yaml` | Parameters only the user sets, each named by the path of its memory field; the interruptors go after `#---INTERRUPTORS---` |
| `Cargo.toml` | Rust crate with six tools: `pla-build`, `pla-recall`, `pla-lint`, `pla-audit`, `pla-verify` and `pla-calc`, plus Verus verification (see `agents/BUILD.md`, `agents/guides/verus.md`) |
| `src/` | Rust code: `lib.rs` (shared memory access and checks), `calc.rs` (the pure calculator), `fantastic.rs` (the 4 fantásticos one by one, and their battery of checks), `pdf.rs` (guide renderer), `verified.rs` (Verus-verified code), `bin/build.rs`, `bin/recall.rs`, `bin/lint.rs`, `bin/audit.rs`, `bin/verify.rs`, `bin/calc.rs` |
| `tests/` | Tests: `tests/wiring.rs` runs the tools against this repo's memory; `tests/logic.rs` checks at run time the contracts of `src/verified.rs` and the laws of arithmetic in the pure calculator; `tests/fantastic.rs` runs every category of AGENTS.md through the battery of `plalast::fantastic` |
| `.secrets/` | Secrets: git-ignored except `.gitkeep`; values are referenced by environment variables, never written in other files |
| `agents/` | Single, provider-neutral source. Its `.md` files (`AGENTS.md`, `CLAUDE.md`, `PROCEDURES.md`, `PROBLEMS.md`, `BUILD.md`, `FEATURES.md`, `LOG.md`, `CHANGES.md`, `INDEX.md`, `user_guide.md` with its `.pdf`) are generated; its subfolders hold hand-written modules and the agent's scratch (`workspace/`) |
| `agents/workspace/` | The assistant agent's own scratch: its scripts, reports, `.md` and `.pdf` files; git-ignored except `.gitkeep`, never part of the brain |
| `agents/skills/<name>/SKILL.md` | Skills, one folder each |
| `agents/subagents/<name>.md` | Subagents of the master architecture (`config.master_arch`) and its cycle (`config.subagent_cycle`): `plalast-writer`, `plalast-verifier`, `plalast-debug` |
| `agents/rules/*.md` | Modular rules by topic |
| `agents/guides/<name>.md` | Guides: hand-written .md sources and the .pdf that `pla-build` renders from each |
| `agents/hooks/` | Hook scripts: `protect-generated.sh` and `session-recall.sh` (Claude Code), `pre-commit` (git), and the generated `claude-settings.json`; their config is `config.hooks` |
| `agents/mcp/<server>.json` | One MCP connector per file |
| `.claude/` | Claude Code adapter: only symlinks into `agents/` (`CLAUDE.md`, `AGENTS.md`, `settings.json`, `skills`, `agents`, `rules`); `pla-lint` refuses anything else |
| `modules/` | Folder for links to the external modules of `primary.modules` (none is built now) |
| `tmux.conf` | tmux config for the `plalast` session, sourced on top of `~/.tmux.conf`; its header comments hold the commands to start it |
